# Popoto
katabameが作成したDalamudプラグインのインストール用リポジトリ

## 利用方法
1. ゲーム内で`/xlsettings`などから「Dalamud設定」を開き、「試験的機能」タブを開いて下さい
1. 「カスタムプラグインリポジトリ」のURLに`https://popoto.kataba.me/pancakes.json`を追加して下さい
